# RHCSA Module 8: Manage Basic Networking
## Module Summary

**Status:** Study material created
**Estimated study time:** 10-14 hours

## Objective Coverage
- Configure persistent IPv4 and IPv6 addresses and routes with NetworkManager.
- Configure hostname resolution using provided DNS and hosts values.
- Set network connections/services to start automatically.
- Restrict network access with firewalld and firewall-cmd.
- Verify active and persistent settings after reload or reboot.

Network profile activation can disconnect remote sessions. Have console access. Open only task-required firewall access; use supplied network values.
