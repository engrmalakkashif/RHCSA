# RHCSA Module 6: Manage Software
## Module Summary

**Status:** Complete study-material draft
**Estimated study time:** 6-8 hours

## Objective Coverage
- Configure access to RPM repositories, including task-provided repository values and GPG verification.
- Install, remove, query, and verify RPM packages with DNF and RPM.
- Configure Flatpak remotes and install/remove applications at user or system scope.
- Verify package/repository state and persistent configuration.

## Safety and Scope
Repository credentials and endpoints are environment-specific. Never disable package signature checking to bypass an error. Practice package removal only in a disposable lab VM.
