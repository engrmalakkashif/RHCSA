## Overview
This module addresses software repositories and package operations (RPM/DNF and Flatpak). Shell scripting is a separate module: [Module 7: Create Simple Shell Scripts](../../Module-7/Module_07_Create_Simple_Shell_Scripts/INDEX.md).

## Learning Paths
- **Beginner (2 days):** Read the notes in order; complete Labs 1–4; review the quick reference.
- **Intermediate (1 day):** Complete Labs 2–4, then verify repository and package state.
- **Exam review (1–2 hours):** Rehearse an RPM repository, RPM package, and Flatpak task.

## Mastery Checklist
- [ ] Inspect enabled and disabled DNF repositories.
- [ ] Configure and verify a repo from task-provided values.
- [ ] Install/remove RPM packages and query package ownership.
- [ ] Add a Flatpak remote and install/remove an application at the requested scope.
- [ ] Verify repository configuration and package state persist at the requested scope.
