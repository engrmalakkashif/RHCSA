# RHCSA Module 7: Create Simple Shell Scripts
## Module Summary

**Status:** Study materials created
**Estimated study time:** 6-10 hours

## Objective Coverage
- Create and execute simple Bash scripts.
- Conditionally execute code with `if`, `test`, `[ ]`, and `[[ ]]`.
- Use loops to process files and command-line inputs.
- Process positional script inputs such as `$1`, `$2`, and `$@`.
- Capture and process output from shell commands.
- Validate syntax, quote expansions, route errors to stderr, and return meaningful statuses.
