# RHCSA Module 9: Manage Users and Groups
## Study Index

## Overview
Create and administer local accounts and groups, set passwords and aging policy, manage group membership, and configure validated privileged access.

**Recommended study time:** 8-12 hours

## Materials
- [Detailed Lab Notes](../09_Manage_Users_Groups_Lab_Notes.md)
- [Lab Exercises](Lab_Exercises.md)
- [Quick Reference](Quick_Reference.txt)

## Topic Map
1. Local identity databases and NSS lookup
2. User creation and modification
3. Password state and aging
4. Groups and memberships
5. Sudo and sudoers validation
6. Persistence and account verification

## Learning Paths
- **Beginner (2–3 days):** Read notes, then complete Labs 1–5 in order.
- **Intermediate (1 day):** Review account commands and complete Labs 2, 3, and 5.
- **Exam review (2 hours):** Create a user, adjust aging, append group membership, configure sudo, and verify all fields.

## Mastery Checklist
- [ ] Create, modify, and safely remove a local user.
- [ ] Set passwords and password-aging/account-expiration values.
- [ ] Create and modify groups and membership.
- [ ] Preserve existing supplementary memberships.
- [ ] Configure privileged access with validated sudoers syntax.
- [ ] Verify UID, GID, groups, home, shell, and policy.
