# RHCSA Module 7: Create Simple Shell Scripts
## Study Index

## Overview
Learn Bash script creation and execution, conditional logic, `test`/`[`/`[[ ]]`, loops, positional arguments, and safe processing of command output and input files.

**Recommended study time:** 6-10 hours

## Topic Map
1. Script creation and execution
2. Variables, quoting, and exit status
3. Conditions and file/string/integer tests
4. Positional input (`$1`, `$2`, `$@`, `$#`)
5. Loops over command-line input and files
6. Command substitution and output processing
7. Safe line-oriented input
8. Syntax checks and debugging

## Learning Paths
- **Beginner (2 days):** Read notes in order and complete Labs 1–5.
- **Intermediate (1 day):** Complete Labs 2, 3, and 5, then write the integration script unaided.
- **Exam review (1–2 hours):** Build a script that validates arguments, tests paths, loops over input, captures command output, and returns accurate status.

## Mastery Checklist
- [ ] Write, syntax-check, and execute a Bash script.
- [ ] Quote variable expansions and handle file names with spaces.
- [ ] Use conditions and `test`, `[ ]`, or `[[ ]]` correctly.
- [ ] Process `$1`, `$2`, `$@`, and `$#` safely.
- [ ] Loop over command-line arguments and input lines.
- [ ] Capture and check output/status from system commands.
- [ ] Report errors on stderr and return meaningful exit codes.
