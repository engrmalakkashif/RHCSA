┌─ SHUTDOWN AND REBOOT ───────────────────────────────────────────────────────┐
│                                                                              │
│  shutdown -h now                - Power off immediately                     │
│  shutdown -r now                - Reboot immediately                        │
│  shutdown -h +5                 - Power off in 5 minutes                    │
│  shutdown -c                    - Cancel scheduled shutdown                 │
│  systemctl poweroff              - Power off                                 │
│  systemctl reboot                - Reboot                                    │
│  systemctl halt                  - Stop system (keep power)                  │
│  poweroff                        - Power off                                 │
│  reboot                          - Reboot                                    │
│  halt                            - Halt (stop)                               │
│  shutdown --show                 - Show scheduled shutdown                   │
│                                                                              │
│  USAGE NOTES:                                                                │
│  - shutdown is graceful (broadcasts message)                                │
│  - poweroff/halt/reboot are faster                                          │
│  - Use shutdown for user systems                                            │
│  - Use poweroff/reboot for scripts                                          │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ BOOT TARGETS AND RUNLEVELS ────────────────────────────────────────────────┐
│                                                                              │
│  systemctl get-default           - Show current default target              │
│  systemctl list-units --type=target                                         │
│                                  - List all targets                          │
│  systemctl set-default graphical.target                                     │
│                                  - Set default target                        │
│  systemctl isolate multi-user.target                                        │
│                                  - Switch to target (no reboot)             │
│                                                                              │
│  COMMON TARGETS:                                                             │
│  graphical.target               - GUI (runlevel 5)                          │
│  multi-user.target              - CLI with network (runlevel 3)             │
│  rescue.target                  - Single-user mode                          │
│  emergency.target               - Minimal rescue                            │
│  poweroff.target                - Poweroff                                  │
│  reboot.target                  - Reboot                                    │
│                                                                              │
│  BOOT PARAMETER:                                                             │
│  At GRUB menu, press 'e' then add:                                          │
│  systemd.unit=multi-user.target  - Boot to CLI                              │
│  systemd.unit=rescue.target      - Boot to rescue                           │
│  Press Ctrl+X to boot                                                       │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ INTERRUPT BOOT PROCESS (RESET ROOT PASSWORD) ──────────────────────────────┐
│                                                                              │
│  1. At GRUB menu: Press 'e' to edit                                         │
│  2. Find 'linux' line                                                        │
│  3. Add 'rd.break' before 'ro'                                              │
│  4. Press Ctrl+X to boot                                                    │
│  5. At dracut> prompt:                                                      │
│     mount -o remount,rw /sysroot                                            │
│     chroot /sysroot                                                         │
│     passwd root                 - Set new password                          │
│     exit (twice)                - Exit and continue boot                    │
│                                                                              │
│  ALTERNATE METHOD (rd.recovery):                                             │
│  In GRUB edit: replace 'ro' with 'rw init=/bin/bash'                        │
│  This mounts / as writable immediately                                      │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ PROCESS MANAGEMENT ────────────────────────────────────────────────────────┐
│                                                                              │
│  ps aux                         - All processes with details                │
│  ps aux --sort=-%cpu            - Sort by CPU usage                         │
│  ps aux --sort=-%mem            - Sort by memory usage                      │
│  top                            - Real-time process monitor                 │
│  top -b -n 1                    - Single snapshot (batch mode)              │
│  top -u username                - Processes by user                         │
│  htop                           - Enhanced process monitor                  │
│                                                                              │
│  TOP NAVIGATION:                                                             │
│  P = Sort by CPU          q = Quit                                          │
│  M = Sort by Memory       k = Kill process                                  │
│  R = Reverse sort         Space = Refresh                                   │
│  h = Help                                                                   │
│                                                                              │
│  PROCESS COMMANDS:                                                           │
│  kill -TERM 1234          - Graceful kill                                   │
│  kill -KILL 1234          - Force kill                                      │
│  kill -9 1234             - Force kill (shorthand)                          │
│  pkill processname        - Kill by name                                    │
│  killall -u username      - Kill all by user                                │
│                                                                              │
│  PRIORITY:                                                                   │
│  Nice range: -20 (highest) to +19 (lowest)                                  │
│  Default: 0                                                                 │
│                                                                              │
│  nice -n 10 command       - Start with low priority (+10)                   │
│  renice -n 5 -p 1234      - Change priority of running process             │
│  ps -o pid,nice,cmd       - Show nice values                                │
│                                                                              │
│  CPU AFFINITY:                                                               │
│  taskset -c 0 command     - Run on CPU 0 only                               │
│  taskset -cp 0 1234       - Bind PID 1234 to CPU 0                          │
│  taskset -cp 1234         - Show CPU binding of process                     │
│                                                                              │

┌─ SECURE FILE TRANSFER ──────────────────────────────────────────────────────┐
│                                                                              │
│  SCP - Secure Copy:                                                          │
│  scp localfile user@host:/remote/path/                                      │

│  mput *.txt                     - Upload multiple                           │

┌─ COMMON SCENARIOS ──────────────────────────────────────────────────────────┐
│                                                                              │
│  1. IDENTIFY RUNAWAY PROCESS:                                                │
│     ps aux --sort=-%cpu | head -2                                           │
│     top (press P for CPU)                                                   │
│     kill -9 PID                                                             │
│                                                                              │
│  2. RESET ROOT PASSWORD:                                                     │
│     Boot to GRUB menu                                                       │
│     Press 'e', add 'rd.break', Ctrl+X                                       │
│     mount -o remount,rw /sysroot                                            │
│     chroot /sysroot                                                         │
│     passwd root                                                             │
│                                                                              │
│  3. ENABLE PERSISTENT JOURNAL:                                               │
│     sudo mkdir -p /var/log/journal                                          │
│     sudo systemctl restart systemd-journald                                 │
│                                                                              │
│  4. SWITCH TO GRAPHICAL MODE:                                                │
│     sudo systemctl isolate graphical.target                                 │
│                                                                              │
│  5. GRACEFUL SHUTDOWN:                                                       │
│     sudo shutdown -h +5 "maintenance message"                               │
│     # Cancel: sudo shutdown -c                                              │
│                                                                              │
│  6. START SERVICE ON BOOT:                                                   │
│     sudo systemctl enable httpd                                             │
│     sudo systemctl enable --now httpd  # Enable and start                   │
│                                                                              │
│  7. COPY FILES SECURELY:                                                     │
│     scp file.txt user@host:/path/                                           │
│     Or rsync -av /source/ user@host:/dest/                                  │
│                                                                              │
│  8. PRIORITY ADJUSTMENT:                                                     │
│     nice -n 15 long_task        - Start low priority                        │
│     renice -n 5 -p PID          - Adjust running process                    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ EXAM TIPS ─────────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. Know the difference:                                                     │
│     - systemctl isolate (immediate, no reboot)                              │
│     - systemctl set-default (default on next boot)                          │
│                                                                              │
│  2. Service commands in order:                                               │
│     enable + start = service runs and starts on boot                        │
│                                                                              │
│  3. Process killing priorities:                                              │
│     - Try SIGTERM first (graceful)                                          │
│     - Use SIGKILL only if needed                                            │
│                                                                              │
│  4. Journal filtering combines:                                              │
│     journalctl -u httpd -p err --since "1 hour ago"                        │
│                                                                              │
│  5. Boot parameter 'rd.break':                                               │
│     - Remember: mount -o remount,rw /sysroot                               │
│     - Then: chroot /sysroot                                                 │
│                                                                              │
│  6. SCP vs RSYNC:                                                             │
│     - SCP: Simple one-time copy                                             │
│     - RSYNC: Synchronization and resume support                             │
│                                                                              │
│  7. Tuned profiles:                                                          │
│     - balanced: Default                                                     │
│     - performance: Maximum speed                                            │
│     - powersave: Minimum energy                                             │
│                                                                              │
│  8. Log persistence:                                                         │
│     - Default: logs cleared on reboot (/run/log/journal/)                   │
│     - Persistent: survives reboot (/var/log/journal/)                       │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  tuned-adm profile performance   # If high performance needed

SCENARIO 3: FILE BACKUP AND TRANSFER
  tar -czf backup.tar.gz /data    # Create compressed backup
  scp backup.tar.gz user@host:/backups/  # Transfer securely
  ssh user@host ls -la /backups/  # Verify transfer

SCENARIO 4: BOOT TARGET CHANGE
  systemctl get-default           # Current target
  sudo systemctl set-default multi-user.target  # Change
  sudo reboot                     # Apply change
  systemctl get-default           # Verify after reboot
