# RHCSA Module 1: Understand and Use Essential Tools
## Module Summary

This module contains detailed notes, quick-reference commands, guided exercises, and an index for essential Linux command-line work.

## Objective Coverage
- Issue shell commands with correct syntax and use input/output redirection.
- Analyze text with grep and regular expressions.
- Access remote systems with SSH and switch users.
- Archive/compress files with tar, gzip, and bzip2.
- Create/edit text files and manage files/directories.
- Create hard and symbolic links.
- Inspect and change standard ugo/rwx permissions.
- Find and use man, info, and installed documentation.

## Files
- `../01_Essential_Tools_Lab_Notes.md`: Detailed topics and examples.
- `INDEX.md`: Topic navigation and learning paths.
- `Lab_Exercises.md`: Hands-on command-line practice.
- `Quick_Reference.txt`: Command syntax and examples.
- `Module_1_Status.txt`: Study checklist.

## Practice Notes
Use disposable test files and directories. Avoid applying recursive permission or ownership changes to system paths. For shared temporary directories, understand the sticky bit (`1777`); world-writable `777` permissions are not a general-purpose setting.
